# 自学通关路线：一个人做完整个项目

> 写给零基础、想独立完成整个数字孪生项目的你。  
> 配套：`Assets/Scripts/B/`（你的参考答案）、`Assets/Editor/BTestSceneBuilder.cs`（一键搭场景）

---

## 0. 先算一笔账（别自我欺骗）

| 方案       | 总人时             | 每周投入    | 需要周数        |
| -------- | --------------- | ------- | ----------- |
| 团队版（3 人） | 144 人时          | 每人 6h   | 8 周         |
| **单人版**  | **约 90~110 人时** | 6h      | **15~18 周** |
| **单人版**  | 约 90~110 人时     | **10h** | **9~11 周**  |

单人省掉了沟通、集成、解冲突的成本，所以总量比 144 少，但**一个人扛不下来 8 周 × 6 小时**。

**结论：按 10 周 × 10 小时规划。** 如果课程只给 8 周 × 6h，必须砍功能（见第 6 节）。

---

## 1. 三条学习原则（比学什么更重要）

**① 不要先学完再做。**  
Unity 知识量是无穷的，你只需要"够用"。每个概念学到能跑通就停，别去看完整的 C# 教程、别啃设计模式。

**② 每个概念都要有"验证动作"。**  
看懂 ≠ 会。判断标准很硬：**能不能在 10 分钟内写个小场景证明你懂了**。本文件第 3 节每个概念都配了自测题。

**③ 先跑通 → 再读懂 → 最后重写。**  
你手上已经有 B 模块 6 个跑得通的脚本，这是最好的教材。顺序千万别反：

- 先让它跑起来（建立信心 + 看到目标）
- 再逐行读懂（知道每行为什么这么写）
- 最后**删掉重写**（这一步才是真正学会，第 5 周做）

## 2. 十周计划表

每周都写清楚：**学什么概念 / 动手做什么 / 怎么算完成**。

### 第 0 周（6h）环境与手感

| 学                                             | 做                                                       | 完成标志        |
| --------------------------------------------- | ------------------------------------------------------- | ----------- |
| 界面四件套：Hierarchy / Inspector / Scene / Project | 建 Cube → 加 Rigidbody → Play → 看它掉下去                     | **看到方块掉下去** |
| 脚本挂载、Update、Inspector 字段                      | 新建 C# 脚本，`transform.Translate(Vector3.forward * 0.01f)` | **方块自己往前爬** |

> 这周唯一目标：把"建物体 → 挂脚本 → Play → 看到变化"这个循环刻进肌肉记忆。后面所有东西都是它的重复。

### 第 1 周（10h）坐标与路径

| 学                                         | 做                                  | 完成标志                                       |
| ----------------------------------------- | ---------------------------------- | ------------------------------------------ |
| `Transform` 父子关系、世界坐标 vs 局部坐标             | 用 `BTestSceneBuilder` 一键搭场景，按 Play | 方块沿 8 个青点跑圈                                |
| `Vector3`、`Mathf`、`InverseTransformPoint` | 逐行读 `WaypointFollower.cs`，给每行写注释   | **能解释 `Atan2(local.x, local.z)` 为什么能算出转向** |

### 第 2 周（10h）射线与调试

| 学                                                                   | 做                                    | 完成标志              |
| ------------------------------------------------------------------- | ------------------------------------ | ----------------- |
| `Physics.Raycast` 四个参数：origin / direction / maxDistance / layerMask | 写个脚本从方块往前射，`Debug.Log(hit.distance)` | Console 打出距离数字    |
| `LayerMask`、`QueryTriggerInteraction`                               | 建 Obstacle / Vehicle 层，射线只打这两层       | 射线不再打到地面和自己       |
| `OnDrawGizmos`、`Debug.DrawLine`                                     | 把射线画成绿/红                             | Scene 视图能看见射线颜色变化 |

> **这周学到的调试技能，价值超过射线本身。**

### 第 3 周（10h）物理与车辆（最难的一周）

| 学                                                               | 做                                                  | 完成标志                        |
| --------------------------------------------------------------- | -------------------------------------------------- | --------------------------- |
| `Rigidbody`：Mass / Drag / 重力                                    | 给车加 Rigidbody，观察质量对加速的影响                           | 能说出 Mass 从 1000 改到 3000 会怎样 |
| `WheelCollider`：Radius / Suspension Distance / Forward Friction | 四个轮子对齐车身，调 Radius                                  | 车轮不悬空、不陷进地面                 |
| `motorTorque` / `steerAngle` / `brakeTorque`                    | 写 `CarController.SetInput(steering, motor, brake)` | **按 WASD 车能开，不翻车**          |

> **这周最容易崩心态。** 官方 WheelCollider 教程（`docs/参考项目清单.md` 有链接）照着做，先用默认参数跑通再调。  
> 卡超过 2 小时就降低标准：车能往前开就行，抖动、打滑都先不管。

### 第 4 周（10h）UI 与闭环

| 学                             | 做                                  | 完成标志                         |
| ----------------------------- | ---------------------------------- | ---------------------------- |
| Canvas / Text / Canvas Scaler | 做 `TelemetryPanel`，显示速度、前车距离、当前 WP | UI 数字随车实时变化                  |
| 简单速度控制逻辑                      | 距离远加速、近减速、太近刹车                     | **车自动沿路径走 + 遇障碍减速 + UI 有数据** |
| 脚本间引用（Inspector 拖引用）          | 把 B 的 `BModuleFacade` 接进速度控制       | 三者串起来跑                       |

> **第 4 周结束，核心闭环跑通——这是整个项目的 1，后面全是 0。**

### 第 5 周（10h）删掉重写 ← 真正的分水岭

| 学           | 做                                                           | 完成标志               |
| ----------- | ----------------------------------------------------------- | ------------------ |
| 不看原文件，凭理解重写 | **把 `Assets/Scripts/B/` 里的文件挪到 `_reference/` 备份，然后自己从零写一遍** | 新写的代码跑起来效果一样       |
| 对比差异        | 写完后打开原文件对照，看哪些地方你想漏了                                        | 能说出至少 3 处"原来要这样处理" |

> 这一步会很难受，但**这是唯一能区分"抄过"和"会做"的关卡**。  
> 写不出来就回去看，看懂了再关掉重写——重复到写出来为止。

### 第 6 周（10h）可视化与多车

| 学                                                 | 做           | 完成标志       |
| ------------------------------------------------- | ----------- | ---------- |
| `LineRenderer`：useWorldSpace / positionCount / 颜色 | 已行驶灰色、未行驶青色 | 路径线随车推进变色  |
| 复制物体做跟驰场景                                         | 复制一辆车跟在后面   | 前车减速后车跟着减速 |

### 第 7 周（10h）稳定性

| 学                      | 做                        | 完成标志              |
| ---------------------- | ------------------------ | ----------------- |
| WheelCollider 摩擦力和悬挂曲线 | 调参，解决高速抖动、转弯侧翻           | **连续跑 5 分钟不崩、不翻** |
| 异常处理                   | 车冲出道路 → `ResetToStart()` | 按 R 能重置           |

### 第 8 周（10h）集成与演示

| 学           | 做                           | 完成标志                |
| ----------- | --------------------------- | ------------------- |
| 场景组织、Prefab | 整合成 Main 场景，参数固定下来          | Main 场景一键 Play 完整演示 |
| 演示流程设计      | 启动 → 自动行驶 → 遇障碍 → 报警 → 到达终点 | 流程顺畅，无卡顿            |

### 第 9~10 周（20h）文档与答辩

报告按模块写：车辆物理 / 感知规划 / 控制集成 / 系统集成。  
录 3~5 分钟演示视频。做 10 页 PPT，**每人只讲自己模块**——单人做就分模块讲。

## 3. 十个必懂概念 + 自测题

| #  | 概念                      | 自测动作（能做到就是懂了）                                          |
| -- | ----------------------- | ------------------------------------------------------ |
| 1  | Transform 与局部坐标         | 解释 `InverseTransformPoint` 返回的 `x > 0` 为什么代表"目标在右边"    |
| 2  | Update vs FixedUpdate   | 说出为什么物理驱动必须放 `FixedUpdate`                             |
| 3  | Rigidbody               | 说出为什么没有 Rigidbody 的物体会穿墙                               |
| 4  | WheelCollider           | 说出 `motorTorque` / `steerAngle` / `brakeTorque` 三者怎么配合 |
| 5  | Raycast                 | 说出四个参数各自的作用，以及为什么必须限制 maxDistance                      |
| 6  | LayerMask               | 解释 `~0` 是什么，`LayerMask.GetMask("Obstacle")` 返回什么       |
| 7  | LineRenderer            | 说出 `useWorldSpace = true` 和不设的区别                       |
| 8  | Gizmos / Debug.DrawLine | 说出为什么 Game 视图看不到 `Debug.DrawLine`                      |
| 9  | Canvas 与 RectTransform  | 说出 Canvas Scaler 为什么必须设置                               |
| 10 | 序列化与 Inspector          | 说出为什么 `public` 字段会自动出现在 Inspector                      |

> 过不了的自测题，就是你要补的洞。**别跳。**

## 4. 调试能力阶梯（比写代码更值钱）

| 层级 | 技能                                   | 什么时候用      |
| -- | ------------------------------------ | ---------- |
| L1 | 看 Console 报错，双击跳转到行号                 | 编译错误       |
| L2 | `Debug.Log` 打印关键变量                   | 逻辑不对但没报错   |
| L3 | `OnDrawGizmos` / `Debug.DrawRay` 可视化 | 坐标、射线、路径问题 |
| L4 | 按 Pause 逐帧看 Inspector 数值变化           | 时序问题       |
| L5 | VS 断点调试（附加到 Unity）                   | 复杂逻辑       |

**90% 的问题用 L1~L3 就能解决。** 先把这三层练熟。

## 5. 卡住预案

| 现象                       | 大概率原因           | 突破方式                                  |
| ------------------------ | --------------- | ------------------------------------- |
| 脚本改了没反应                  | 没保存 / 编译报错      | VS 里 Ctrl+S，回 Unity 看 Console         |
| `NullReferenceException` | Inspector 里引用没拖 | 双击报错跳到行号，回去拖引用                        |
| 车原地打转                    | `steerGain` 太大  | 从 2 降到 1.5                            |
| 车转不过弯                    | 转向力度不够          | `steerGain` 调到 3，或 `arrivalRadius` 调大 |
| 射线一直说有障碍                 | 打到自己/地面         | 检查 Layer，别勾 Default                   |
| 看不见 Gizmos               | Scene 视图右上角关了   | 点亮 Gizmos 按钮                          |
| 车抖得像筛子                   | 物理在 Update 里更新  | 物理操作移到 FixedUpdate                    |
| 怎么都调不好                   | 参数太多            | **一次只改一个参数**，记在纸上                     |

## 6. 单人版必须砍的东西

时间不够时，**按这个顺序砍**（越靠前越先砍）：

1. MATLAB 联动（`docs/MATLAB联动方案.md` 留着，有余力再上）
2. 多视角摄像机切换
3. A* 路径规划
4. 历史速度曲线
5. 场景美化（路灯、建筑、树木）
6. 多车跟驰

**无论如何要保住的：**  
车辆能开 → 射线检测 → Waypoint 跟踪 → 速度控制 → UI 报警

这五样就是"核心闭环"，**缺一个都算不上做完了**。

## 7. 最终自测（自己给自己答辩）

全部打勾才算通关：

- [ ] 按 WASD 车能开，不翻车
- [ ] 射线能检测前方障碍，Scene 视图看到颜色变化
- [ ] 车能自动沿 Waypoint 跑完一圈
- [ ] 前车距离 < 5m 时减速，< 3m 时停车
- [ ] UI 实时显示速度、前车距离、当前 WP 编号
- [ ] 路径已行驶/未行驶用不同颜色
- [ ] 能连续跑 5 分钟不崩溃
- [ ] 车冲出道路能重置
- [ ] 能说清每个脚本的职责
- [ ] 能画出系统架构图（传感器 → 决策 → 执行 → UI）
- [ ] 报告里能解释每行核心代码
- [ ] 被问"为什么这么设计"时有答案

> 最后一条最重要：**答辩老师问的不是"你做出来了吗"，是"你为什么这么做"。**
